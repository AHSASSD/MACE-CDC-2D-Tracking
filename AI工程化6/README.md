## 输入与实现

- 每个 EvtID 整体处理；固定随机种子 20261105，从既有划分抽取 128 train / 32 validation / 32 pilot test。
- d 直接使用既有带误差值；不添加误差、不使用任何时间字段。Good 与 CreatProc 过滤保持原完整事件流程一致。
- CellID 仅定位几何；HitID 保留独立记录身份，不作为网络特征。重复击中同一丝不会被去重。
- 12 维节点：丝参考 x/y/r、d、方位正余弦、u/v/w、长度、丝类型、归一化半径。末项与已有半径特征冗余，首轮保留以冻结实验配置。
- 11 维边：参考半径差、参考横向距离、方位差及距离归一化方位差、共同有限 z 范围内最小横向距离及其 z、共同半长、d 差、方向点积、两端丝类型。
- 在 z=0 参考点及归一化方向、丝长约定下，使用两丝共同有限 z 范围内最小横向距离 <=120 mm 建边。参考点绝不作为斜丝的真实 hit 位置进行圆拟合。此规则仍是宽松局部候选，不等于三维径迹兼容性判据。
- 网络复用原 InteractionNetwork，hidden=64、3 次消息传递；联合网络与旧 hidden=256、8 次传递的基线容量不同，不能将结果差异全部归因于是否加入斜丝。
- BCE 标签仅为同一事件中的同 TrkID；真值不参与特征或建边。

## 实验目录

- `pilot_v1/`：8 轮 GPU 训练，数据缓存、原始 CSV/几何/基线哈希、划分、检查点、测试报告。
- `mean_ablation/`：仅将消息求和改为按入度取均值，固定相同初始化种子与 8 轮训练，仅验证，不重新测试。
- `extended_sum/`：从 pilot 最佳模型继续训练；保存 3 轮检查点后，因 GPU 接近满显存且长时间不推进，停止该训练进程。
- `cpu_extension/`：从上面的 last.pt 继续本机 CPU 训练，完成两轮后保存权重；优化器重新初始化。
- `memory_safe_gpu/`：从 CPU 阶段最后权重继续训练 24 轮；反向重算边 MLP 激活，限制 CUDA 进程显存预算，并释放事件间缓存。输出和梯度等价性已验证。此目录保存最终检查点、独立测试结果与比较图。
- `evaluate_fresh.py`：训练/阈值冻结后，从原 test 划分抽取另一批未见过的 32 个事件进行一次评估；明确排除 pilot test。

首轮 sum/mean 的最佳验证 AA/AS/SS 宏 F1 分别为 0.56066 / 0.55492，因此暂时保留 sum。pilot 测试 AA/AS/SS F1=0.6172/0.4453/0.3913，基线 AA F1=0.8966。此时联合模型不优于基线。后续选择只依据 validation，pilot test 视为已暴露探索集。

## 评分限制

本轮主要验证 hit 关联。候选评分对两模型使用同一连通分量解码器，候选至少包含 5 个直丝 hit，以直丝 purity/completeness 均 >=70% 匹配；真轨分母只由直丝决定。最终独立评估时，候选阈值另行仅按验证集上的 (matched -0.25*fake -0.25*clones)/truth 选择，不直接沿用边 F1 阈值；记录见 decoding_validation.json。此解码器容易受少量假边串联影响，结果不得替代原项目两级寻迹的正式性能。报告另列斜丝纯度/完整度、假候选、克隆和耗时；斜丝完整度仅对成功匹配候选计算，应与总匹配率一起阅读。

没有将斜丝参考位置送入直丝漂移圆拟合。当前没有三维拟合成功率和动量结果；在关联质量足够之前，不宣称已完成三维重建。
