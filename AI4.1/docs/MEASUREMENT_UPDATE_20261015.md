# 2026-10-15测量口径更新：精确模拟时间不可直接作为实验输入

本说明优先于本版本历史报告中“真实时间是否可获取尚未知”的表述。**数值实验结果保留，但time33及时间回收成绩均降为理想时间输入下的模拟研究对照，尚未验收可测时间输入下的重建效果。**

## 新信息及来源

用户转述实验方的最新反馈，并提供聊天截图供本次核对：

- 模拟中的精确时间不能在实际MACE实验中直接取得。
- 可取得的是大概的时间零点及漂移时间。
- 漂移距离d由漂移时间换算；因此d与时间不是随意独立的两路测量。
- 聊天中用`t−tHit`解释漂移时间。具体符号还需与CSV导出和读出链统一，不能把模拟真tHit当作已经测得的参考。

以上属于用户提供的实验沟通信息，不是完整电子学标定文件。公开仓库只保存技术结论，不保存私人聊天截图、姓名或账号。

## 必须区分的变量

| 量 | 当前模拟中的定义/用途 | 真实输入的要求 |
|---|---|---|
| CSV `t` | 本地源码为`signalTime=hitTime+driftDistance/v`；与CSV实测关系一致 | 不可直接把这个无分辨率的理想值当读出 |
| CSV `tHit` | 模拟物理击中时间，同丝聚合时可能平均 | 不得作为已知真时刻送入网络或反算线上漂移时间 |
| CSV `t0` | 模拟轨迹出生时刻 | 不等于已测量的TDC参考零点 |
| `T0_meas` | 当前完整事件训练未显式模拟的测量参考 | 需明确分辨率、公共时钟、共享范围及与hit的关联 |
| `tau_drift_meas` | 应来自真实读出的漂移时间差 | 与T0/信号误差联合模拟，避免重复加噪 |
| `d_meas` | 当前是几何真距离＋0.5mm扰动 | 应按标定关系`r(tau_drift_meas)`形成，并保持时间/距离相关性 |

此前沟通的约3ns是漂移时间差的分辨率口径，不能不经确认就当作粗时间零点的误差，也不是将每一路TDC都独立加3ns。粗T0的分辨率、参考共享范围及关联机制尚未给出。

## 对现有结果的影响

1. **time33的98.7334%测试效率**：仍是已完成的模拟实验数值，但不再作为当前真实读出的可部署性能证据。代码未直接读取标签，不等于使用的信息在现实中可测。
2. **时间分峰Hough、时间约束延长/合并**：依赖`tau=t_obs−d/v`，当前理想输入可近似还原含轨间出生时刻的信息，同样受本次口径问题影响；95.8951%等成绩不能直接宣称真实回收收益。
3. **独立3ns、14.29ns及同步d/t扰动对照**：仅改变当前理想时间的噪声，仍保留其轨间绝对时间结构；它们不能替代粗T0与真实漂移时间的联合读出模型。
4. **no-time**：不读取时间通道，保留作空间研究基线。但其d仍是模拟加噪替代量，也需实际r-t标定与噪声/死时间验收；不能因此自动称已验证真实实验性能。

现有数值审计显示，扣除各粒子真出生时刻后固定time模型效率从98.66%降至64.08%，支持模型依赖轨间时间结构。该真值干预不是实际测量方案，也不能作为真实时间口径下重新训练网络的性能上限。

## 下一步应验证什么

- 先定义实际可获取的`T0_meas`和`tau_drift_meas`，确认它们是全事件共享、逐轨参考还是逐hit读出，以及关联过程是否已经需要寻迹。
- 用同一读出模型联合生成时间、漂移距离及误差协方差；如果0.5mm包含额外扩散/标定误差，应明确来源，而非直接用3ns替代。
- 在有依据时，可用测量参考与漂移时间构造可测信号时间；不能从MC真tHit/真t0恢复理想时间后重新命名为“观测时间”。粗时间仍可能有用，但必须在真实可测口径下重新训练并对照no-time。
- 时间回收算法使用同一可测输入重新验收，再报告净增真轨、假轨、克隆及独立测试结果。
