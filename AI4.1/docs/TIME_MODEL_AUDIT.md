# time模型：未发现直接标签泄漏，但存在时间信息捷径

截至2026-10-15。完整代码核查、测量统计和敏感性试验见[审计报告](../reports/time_audit/time模型作弊与时间口径核查.md)及其同目录JSON。

**审计后新增实验反馈：模拟中的精确时间不可直接取得，可测量粗时间零点与漂移时间，d由后者换算。此前“是否可获取”的开放问题已推进为明确的输入口径不匹配。time33目前仅保留为理想时间模拟对照；完整更新见[这里](MEASUREMENT_UPDATE_20261015.md)。**

## 已核查的内容

- 全10000个图的7000/1500/1500事件划分完整、互斥；跨划分精确测量事件和轨迹签名重复均为0。
- 原CSV的NativeEvtID+SourceShard、PoolEvtID没有跨输出事件重用。未检查缺失的上游primaries.root，精确检查也不能排除重新加噪的近重复。
- 网络仅接收几何、测量d、事件内信号时间和边差值；没有把真t0、tHit、d_true、标签y或ID直接送入forward。
- CPU上修改标签、真轨ID和事件ID，预测逐值不变。重排节点后预测仅有约1e-6以下数值波动。
- 从原CSV重建10个事件，输入、候选边和标签与图分片逐值相同；改变TrkID会改变标签而不改变输入/候选边。

上述证据不支持“代码直接拿答案”，但不等于真实测量信息已经验证可用。

## 为什么高分与快收敛并不矛盾

time33是已有time模型的微调，不是从零训练33轮。当前1500验证事件的信号时间跨度中位数约8.97μs，单轨hit跨度中位数140.7ns。在空间候选边上，同轨时间差中位数50.5ns，异轨为1632.8ns，因此时间能强烈排除大量跨轨边。

3ns误差小于大部分轨间差异；不能把“分不清几十ps的先后顺序”理解成“百纳秒到微秒的时间分组也没用”。

## 固定模型消融

同一203个验证事件、6035条合格真轨，固定权重和0.70/0.575阈值。结果与1500事件整体98.8110%的分母不同。

| 诊断条件 | 效率 |
|---|---:|
| 原始time33 | 98.66% |
| 独立逐hit 3ns扰动（既有同种子结果） | 98.72% |
| 独立逐hit约14.29ns扰动 | 98.64% |
| d的扰动同步反映到t | 98.62% |
| 消除各真轨的时间中位数差 | 69.86% |
| 扣各粒子真出生时刻 | 64.08% |
| 全部时间置零 | 53.07% |
| 事件内随机打乱时间 | 3.58% |

这说明模型强烈依赖轨间时间分离，未支持“仅漏加几ns误差就解释全部高分”。消除中位数/真出生时刻使用真值，仅是离线诊断，绝不可作为部署输入；分布改变后的64.08%等数值不是重新训练纯漂移时间模型的性能上限。

仅用`|Δ(t−d/v)|≤50ns`的固定规则，在相同空间候选图和两级几何后处理中达到82.80%，边F1约96.04%；网络仍比这条简单门限强，不能说时间差已经完全等于标签。

## 最重要的风险：当前(d,t)与真实测量口径不同

CSV近似满足`t=tHit+d_true/v`，d另加σ=0.5mm误差。于是`t−d/v`近似恢复包含各粒子出生时刻的hitTime。真实系统若确实能同时测到正确每hit漂移距离和共同参考下的绝对信号时间，这是合法信息。

但若真实d来自同一t扣一个全事件共同参考再换算，`t−d/v`应接近共同参考，不能自动得到本数据的逐轨时间标签。若d计算需要先知道各粒子的参考时刻，则必须说明参考时刻如何测得、如何与每个hit关联。模拟直接提供“真几何距离加噪声”尚未验证这一步。

另外，3ns×0.035mm/ns=0.105mm，而0.5mm对应14.29ns，两种误差口径并不等价。d/t噪声是否来自同一TDC、参考共模、扩散及标定误差，需要统一建模；同步噪声对照不代表已解决联合可观测性。

## 两种实际输入条件

1. **绝对信号时间和正确d均可获取**：当前模拟结果可能成立，但需进一步验证读出窗、通道偏移、参考响应、噪声和死时间。减去全事件共同触发时刻不会抹掉轨间时间差。
2. **只有漂移时间，或只能保留较短读出窗**：当前结果不能直接迁移。纯漂移时间应重新定义输入并训练；短窗应重建窗口内事件和真轨分母，二者不是同一种任务。不能直接把真t0当作实际测量参考。

Good与CreatProc筛选、无额外噪声和完整模拟事件窗口，也使当前任务不同于未知真实hit集合。98%以上表示“当前筛选模拟＋至少50%完整度匹配”的效率，不是完整实验的全hit回收率。

当前建议：保留现有模型作为理想时间模拟基线，停止将其指标用作真实输入的能力证明；按可测的粗T0、漂移时间及其相关d重建输入，再训练并做独立验收。粗T0的分辨率与共享范围仍未知，不能用独立3ns扰动代替。历史两种条件分析只解释模型依赖，不构成当前输入已被实验确认可测。
