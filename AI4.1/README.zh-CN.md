# AI4.1：完整事件寻迹与时间信息审计

[English](./README.md) | [简体中文](./README.zh-CN.md)

AI4.1 是本地“AI工程化4 - 副本”的研究快照，记录截至 **2026-10-15** 的完整事件重训、两级寻迹、片段回收和时间分峰 Hough。它作为独立目录发布，未替换仓库中的冻结 AI4 或实验 AI5。

**测量口径更新：实验方反馈精确模拟时间不可直接测得，只能获得粗时间零点与漂移时间，d由漂移时间换算。当前time模型及时间回收结果均为理想时间输入下的模拟对照，尚无真实可测输入验收。** 见[最新信息及影响](docs/MEASUREMENT_UPDATE_20261015.md)。

## 当前结果

匹配要求：真轨至少5 hit、候选纯度≥0.8、完整度≥0.5。效率按真轨计；假轨率/克隆率按输出候选计，不是边分类准确率或全部 hit 回收率。

| 模型/流程 | 数据组 | 效率 | 假轨率 | 克隆率 |
|---|---|---:|---:|---:|
| no-time 微调62轮＋原两级寻迹 | 1500验证事件 | 93.7762% | 4.4130% | 0.1285% |
| 同权重＋时间约束延长合并 | 同一验证组 | 94.4957% | 3.4250% | 0.0882% |
| 同权重＋上述回收＋时间分峰Hough | 同一验证组 | 95.8951% | 3.4069% | 0.0891% |
| no-time 从头训练88轮＋原两级寻迹 | 1500测试事件 | 93.6578% | 4.9328% | 0.1000% |
| time 微调33轮＋原两级寻迹 | 同一1500测试事件 | 98.7334% | 1.8907% | 0.4899% |

回收属于**固定网络后的组轨改进**，不是重新训练提升网络；使用时间回收的 no-time 流程不能称为全流程无时间。time＋Hough、双专家融合、门控MoE尚无验收结果，不能把表中收益相加。

## 目录

- `STEP1_完整事件数据集.py` / `STEP2_训练模型.py`：完整事件预处理、重训与严格断点恢复。
- `common.py` / `STEP4_两级寻迹.py`：两套输入、消息传递网络、圆拟合及两级组轨。
- `fragment_recovery.py`：可选的观测时间约束片段回收和三漂移圆参数投票。
- `STEP6_事件切片可视化.py` / `STEP6_绘图界面.py`：EvtID闭区间切片、PNG和圆/hit关联JSON。
- `STEP7_双专家验证.py`：固定概率融合研究入口，**不是已训练MoE**。
- `real_data_evaluation/`、`tools/`：研究脚本和可复核的时间泄漏诊断。
- `whole_event_retraining/`：推理权重、配套元信息与事件划分；[权重哈希目录](MODEL_CATALOG.json)。
- `reports/`：原始阶段报告、汇总指标和图。部分历史报告描述的是当时状态，最新结论以上述三份专题文档为准。

## 快速运行

先安装仓库根目录依赖及本目录补充依赖，并配置丝几何表；原始CSV、Excel和图分片需自行提供，详见[运行说明](docs/REPRODUCTION.md)。

```powershell
cd AI4.1
$env:MACE_CDC_CELL_MAP = 'D:/your-data/cdc_cell_map.xlsx'
python STEP4_两级寻迹.py --features time --dataset-root whole_event_retraining --run-tag expert_whole_events_sigma05 --split test --rounds 1500 --strict-threshold 0.70 --relaxed-threshold 0.575
```

## 发布范围与限制

代码、小型推理权重和汇总证据已包含；原始实验数据、训练图分片、优化器断点、预测缓存、IDE配置及SSH/集群账号配置不上传。大型数据缺失时无法直接执行全量重建。

time 模型未发现直接标签泄漏或跨划分精确重复，但显著依赖模拟中的轨间绝对时间差。最新反馈已否定直接获取无分辨率精确时间的假设；需按粗T0、测量漂移时间及相关d重建输入。98%以上只对应当前模拟筛选与匹配口径，不能作为实际实验效率承诺。
